📗 What is Claude in Excel?

Claude in Excel is an add-in that puts a Claude chat panel directly inside Microsoft Excel. You can describe the analysis you want in plain English — "show me denial rate by payer" — and Claude generates the formula, pivot table, or chart for you. It sees your data and can work with it directly. This week you're using it to answer all 7 dashboard KPIs before writing a single line of Python.

📗 Day 6 Excel Prompts — Try These in Order
"I have a claim CSV with columns: claim_id, service_date, payer_name, cpt_code, icd_code, billed_amount, status, denial_reason. Calculate the overall denial rate as a percentage."
"Create a pivot table showing denial rate by payer. Sort it from highest to lowest denial rate. Which payer should we be most concerned about?"
"For claims where status = 'denied', group them by denial_reason and count how many claims have each reason. Which reason code appears most?"
"Calculate days in A/R: the average number of days between service_date and today for all claims where status = 'pending' or 'denied'. What does this tell us?"

⚙️ What is Cowork?

Cowork is a desktop automation tool from Anthropic that lets non-developers automate file management, folder organisation, and repetitive computer tasks using plain English instructions. You describe what you want Claude to do — "every Monday, move this week's exports to this folder and rename them with today's date" — and Cowork handles the rest. This week you'll use it to automate the manual data prep steps that billing staff do before they can analyse anything.

📐 Master System Prompt Structure
RoleWho Claude is in this context (experienced billing analyst, not a general AI assistant)
TaskWhat it does (generates a structured daily briefing from real metrics)
ConstraintsWhat it must not do (invent data, give clinical advice, name specific patients)
Output formatExact XML tags: <summary>, <alerts>, <top_issues>, <recommendations>
ToneHow it should sound (direct, professional, action-oriented — not academic)
ContextWhat the user message will contain (a structured block of real metrics)

💻 The Claude Code Mental Model — Read This Before Monday
What it isA command-line AI coding assistant that works in your terminal alongside your code editor. You describe what you want to build, and Claude Code writes the code, tests it, debugs errors, and explains what it did.
What changesYou stop typing code and start directing. Your job is to: describe requirements clearly, review what Claude Code produces, test it, and decide whether it meets the spec — not to write every line yourself.
What stays the sameYou still need to understand the code. If Claude Code produces a function you don't understand, you ask it to explain. You can't approve code you can't evaluate.
The new skillWriting good requirements. The better you describe what you want — in precise, testable terms — the better Claude Code's output. All of Week 1's KPI definitions and Week 2's prompt experiments directly apply here.
