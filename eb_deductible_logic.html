Reusable Logic — Reading Any E&B for Deductible Applicability

1
Identify the plan type and tier structure
Look for "Active Health Plan" in the E&B header. Determine if it's an HMO, PPO, HDHP, EPO, or multi-option (like this "Triple Option"). Multi-option plans will show multiple tiers in the benefit detail rows. The tier that applies is determined by the rendering provider's network participation — confirm via provider directory or NPI lookup before proceeding.
IF plan_type == "HMO": → copay-only structure; deductible rare
IF plan_type == "HDHP": → deductible applies first on nearly all services
IF plan_type == "PPO": → depends on service type and POS; check each row
IF plan_type == "Multi-Option": → determine which sub-tier applies first
2
Find the service type row matching the visit
Match the service being rendered to the E&B benefit rows. Key identifiers in CareFirst-style documents include service type labels (Office Visit, Infusion Therapy, Emergency Room, etc.) paired with a CMS service type code in parentheses. Match on both label AND the network tier/provider role that applies to your provider.
Example service type codes found in this E&B:
200 = Chiropractic  |  280/290/300 = Emergency  |  418/422 = Infusion
469 = Nutrition Counseling  |  470 = Office/Clinic Visit  |  640 = Inpatient
740/742 = Urgent Care  |  122 = Outpatient Observation
3
Check the place of service — it changes deductible status
This is the most commonly missed factor. The same service can have different deductible rules depending on place of service. In this plan, infusion at an office POS has no deductible, but the same infusion at an outpatient hospital POS has "DEDUCTIBLE APPLIES." Always confirm and document the place of service before determining liability.
CareFirst POS deductible pattern for this plan:
Office (POS 11) → typically NO deductible (copay only)
On Campus Outpatient Hospital (POS 22) → often DEDUCTIBLE APPLIES
Inpatient Hospital (POS 21) → often DEDUCTIBLE APPLIES
4
Scan for the explicit "DEDUCTIBLE APPLIES" flag
CareFirst and most modern 270/271 E&B responses explicitly embed the text "DEDUCTIBLE APPLIES" in the benefit description when applicable. If the phrase is present on the matching service row → deductible applies. If the phrase is absent AND a flat copay is shown with 0% coinsurance → deductible does not apply for that service/tier combination.
SEARCH benefit_text FOR "DEDUCTIBLE APPLIES"
IF found → deductible applies
ELSE IF copay_present AND coinsurance == 0% → NO deductible
ELSE IF "Deductible $0.00 Contract" present → NO deductible for this service
5
Check deductible accumulation (remaining vs. total)
Even if the deductible applies structurally, it may already be fully or partially met. Look at the deductible remaining amounts for both the individual and family. Use whichever is lower (the one that will be met first). If remaining = $0 → skip to coinsurance. If remaining > $0 → the patient owes up to the remaining amount at the allowed rate before coinsurance begins.
For Gabriela as of 05/06/2026:
Individual deductible remaining: $200.00 (fully unmet)
Family deductible remaining: $600.00 (fully unmet)
→ Any deductible-applicable service: patient owes up to $200 individually
6
Check for preventive service overrides
Both ACA mandates and plan-specific waivers can eliminate cost sharing entirely. In this E&B, look for: "COST SHARING MAY NOT APPLY FOR PREVENTIVE SERVICES" and "MANDATED BENEFIT WAIVES COST SHARE IN-NETWORK AND OUT-OF-NETWORK." If either phrase appears and the visit is coded as preventive (wellness, screening, etc.) → $0 patient liability regardless of deductible status.
7
Calculate patient liability
Combine the findings above into a final patient responsibility estimate. Always use the payer's allowed amount (not billed charges) as the basis.
IF deductible_applies == False: patient_owes = copay_amount
ELSE IF deductible_remaining == 0: patient_owes = allowed × coinsurance_pct
ELSE IF allowed <= deductible_remaining: patient_owes = allowed
ELSE: patient_owes = deductible_remaining + (allowed - deductible_remaining) × coinsurance_pct
Cap final result at individual OOP remaining: $890.00
