🔵 Claude in Chrome — What It Is

Claude in Chrome is a browser extension that puts Claude directly in your browser. You can highlight text on any webpage and ask Claude to explain it, summarize it, or connect it to something else. This week you'll use it to turn dense medical billing documentation into plain English.

Install it from the Chrome Web Store — you need a Claude.ai account. Once installed, a Claude icon appears in your browser toolbar.

Afternoon: Core Billing Vocabulary — The Language of the Job
You can't shadow billing staff or read denial reports without knowing these terms cold
~2 hrs▼
CPT Code
5-digit procedure code — describes what was done. Example: 99213 = office visit, established patient, moderate complexity.
ICD-10 Code
Diagnosis code — describes why it was done. Example: J06.9 = acute upper respiratory infection.
CARC Code
Claim Adjustment Reason Code — explains why a claim was denied. CO-97 = "bundled service." These are the codes the dashboard will track.
Denial Rate
% of submitted claims that were denied. The #1 metric for billing health. Industry average: 5–10%. Anything over 15% is a red flag.
Clean Claim Rate
% of claims accepted on first submission without errors. Higher = more efficient billing.
Days in A/R
Average days a claim sits unpaid. Target: under 40 days. Over 60 days = significant cash flow risk.
EOB
Explanation of Benefits — the payer's response to a claim showing what was paid, denied, or adjusted.
Prior Authorization
Pre-approval required from the payer before certain procedures. Missing it is one of the most common denial causes.
